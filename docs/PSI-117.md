# PSI-117: analyzed droplet cool-flame data (n-heptane, n-decane, n-dodecane)

Location: `data/PSI-117/` (9 CSV + 1 ReadMe workbook). Treat this folder as **read-only**, like `data/raw/`.
All fixes happen in code.

## What it is (and what it is not)

- **Investigation:** *Effect of External Thermo-Convective Perturbation on Cool Flame Dynamics: A Multidimensional
  Multi-Physics CFD Analysis*. PSI id PSI-117, DOI **10.60555/gz0q-b577**,
  https://psi.nasa.gov/physci/repo/data/investigations/PSI-117 (the page renders with JavaScript, so its other
  metadata was not scraped).
- This is a **computational (CFD) investigation**. The "Analyzed Data" are **digitized figure data**: simulation
  curves plus the experimental points the papers compare against, behind four published papers. It is **not** an
  experimental table: there is no row per test and no test id, so you cannot join it to FLEX (PSI-69) or CFI (PSI-39).
- Fuels: n-heptane (C7), n-decane (C10) and n-dodecane (C12). FLEX in this repo has only methanol and heptane.
  The experimental series most likely come from the ISS droplet cool-flame runs (the CFI test log, PSI-39, lists
  C12H26 tests). **Not confirmed.**
- `data/raw/meta.json` has no PSI-117 entry. Don't edit it: it lives in the read-only raw folder. The metadata
  lives here instead. Data received 2026-11-14.
- License: assumed CC0-1.0 like the rest of PSI. Check this on the PSI record.

### Intended use in this project

| Use | OK? |

## File format (all files)

- **Wide, multi-series layout.** Each CSV stacks several independent series side by side, separated by empty
  columns. The series have different lengths, so the shorter ones are padded with empty cells. Never read these
  files as one rectangular table. Split them into column blocks at the empty separator columns, then drop the
  trailing empty rows of each block.
- **Metadata inside the data area.** The first column of a block often holds labels in its first 1–3 data rows
  (`EXP`, `Model`, `Expt`, `Sim`, `1 atm`, `do 4 mm`, `Radiance 5 atm`, ...). Parse these labels into series
  metadata, not into values.
- **Repeated and inconsistent headers:** `t` / `time` / `time ` / `Time(sec)` / `t (s)`, and `Q(W)` / `Q (W)`.
  pandas would rename the duplicates to `t.1`, `Q (W).1`, and so on. Map each block explicitly.
- **Encoding:** UTF-8 with a BOM in 8 of the 9 files (`MST_2024_Kavg.csv` has none), so read with `utf-8-sig`.
  All files use CRLF line endings.
- **Units:** diameters in mm, pressure in atm, time in s, burning rate K in mm²/s, Q and radiance in W, and
  temperature in K. `t/(Do)2` is in s/mm². `Kavg_CF` has no unit in its header; assume mm²/s.

## Known quirks: flag them, don't silently fix them

R1. **ReadMe compositions are inconsistent.** The PROCI 2019 rows give X_O2 as a fraction (0.21 / 0.10) but
    X_N2 as a percentage (74 / 85), and a column labelled `XO3` holds "Balance". That column header is very likely
    a typo for another diluent; check the paper. Sums: 0.21 + 0.74 = 0.95 and 0.10 + 0.85 = 0.95, so 5 % of
    the mixture is unidentified.
R2. **The ReadMe range is narrower than the data.** `MST_2024_Dext` says 0.5–1.5 atm, but the model block goes to
    3 atm. `MST_2024_Radiance_Flame_Diameter` says d₀ ~4.5 mm, while the CSV labels say 4.46 and 4.48 mm.
Z1. **Zero means "not observed", not a diameter of 0 mm.**
    - `Dext_CF = 0` in two C12 experiments (Alkane file).
    - `Dext_cool = 0` in the model at 3 atm (MST Dext).
    - `Dext_CF_EXPT = 0` at 3 atm, with zero error bars (C12 vs pressure).
    - `Dext_HF = Dext_CF = 0` in the C7 and C10 simulations at d₀ = 2 and 3 mm.

    Convert these zeros to null plus an `observed=False` flag before computing any statistics. This is the same
    pattern as FLEX quirk 4 (d_ext 0.0 = "no extinction").
D1. **Negative digitized values that are physically impossible:** `Dflame/Dodrop` min −0.158, `Dflame (mm)` min
    −0.053 and `Cool Flame Dia (peak-peak)` min −0.121 (Three_Stage). This is digitization noise around zero.
    Flag the rows; don't clip them.
D2. **Negative normalized time:** `t/(Do)2` goes down to −0.20 s/mm² (Three_Stage). This is probably time before
    the reference instant (ignition or deployment), so it is legitimate. Confirm in the paper (Fig. 7).
D3. **Exact duplicates in `MST_2024_Kavg` experiment:** (0.5 atm, 0.315175121) and (1.25 atm, 0.431540259) each
    appear twice. These could be two runs with identical values or a duplication error. Keep both and flag them.
S1. **Negative simulated K** (down to −4.08 mm²/s in Three_Stage and −0.28 in the PROCI 2019 files) at early
    times. This is droplet heat-up and swelling before steady burning: real physics, not an error. Note it in the
    d²-law discussion.
S2. **Simulated flame diameter starts at about 80–100 mm at t ≈ 0** (MST burning history 79.7 mm, Radiance file
    100.3 mm, Three_Stage 81 mm). This is an ignition-kernel initialization artifact of the model. Exclude the
    first instants from plots or label them.
F1. **Format issues:**
    - `MST_2024_Kavg.csv` has no BOM, unlike the other eight files.
    - `PROCI_C12_2019_Three_Stage.csv` ends with one fully empty line.
    - The Model label in the burning-history file is spelled both `do 4 mm` and `do 4mm`.
    - The second `time, Q (W)` experimental block in the burning-history file has no label saying what it measures.
